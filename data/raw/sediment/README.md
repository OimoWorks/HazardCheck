# 土砂災害警戒区域データ（急傾斜地の崩壊・土石流・地すべり）

⚠️ 以前は `sediment-steep/` `sediment-debris/` `sediment-landslide/` の3ディレクトリに
分けて配置する想定だったが、実際に配布されるデータ（国土数値情報 A33 土砂災害警戒区域）は
**1ファイルに3種類の現象がすべて含まれ、属性値で判別する形式**だったため、このディレクトリ
1つに統一した。

## 入手元
国土数値情報ダウンロードサービス（<https://nlftp.mlit.go.jp/ksj/>）の「土砂災害警戒区域データ
（A33）」から、松山市を含む範囲（例: 中予地域・松山地区など、複数市町にまたがる場合がある）の
GeoJSONをダウンロードする。ファイル名の例: `A33-25_38Polygon.geojson`
（`38`は愛媛県の都道府県コード）。

## ここに置くもの
ダウンロードしたGeoJSON（`*.geojson` / `*.json`）をこのディレクトリ直下にそのまま置く。
Shapefileで配布されている場合は `*.shp` `*.dbf` `*.shx` `*.prj` を同じベース名で置く
（`scripts/build-hazard-data.js` は本ディレクトリ内の全ファイルを自動でマージする）。

## データ構造（属性）

1地物（ポリゴン）ごとに以下の属性を持つ。

| 属性名 | 内容 | 値 |
|---|---|---|
| `A33_001` | 現象の種類 | `1`=急傾斜地の崩壊, `2`=土石流, `3`=地すべり |
| `A33_002` | 区域区分 | `1`=警戒区域(指定済), `2`=特別警戒区域(指定済), `3`=警戒区域(指定前・基礎調査結果), `4`=特別警戒区域(指定前・基礎調査結果) |
| `A33_006` | 所在地（市区町村名を含む文字列） | 例: `松山市久谷町`、`伊予市中山町佐礼谷` |

`A33_002` が `3`・`4` の地物は、まだ法的に指定された警戒区域ではなく、都道府県が基礎調査を
行った結果が公表されている段階にすぎない。アプリの表示上も「指定済み」の`1`・`2`とは
文言を変えて区別する（`scripts/build-hazard-data.js` の `ZONE_TYPE_MAP` 参照）。

## 松山市分の絞り込みについて

ダウンロードした範囲には松山市以外の市町（東温市・伊予市・今治市・久万高原町など）の
データも含まれることが多い。`scripts/build-hazard-data.js` は、まず `A33_006`（所在地）に
「松山市」を含む地物だけを抽出する（この属性による絞り込みができない場合のみ、
`data/raw/matsuyama-boundary/` の行政区域境界とのポリゴン交差判定にフォールバックする）。
