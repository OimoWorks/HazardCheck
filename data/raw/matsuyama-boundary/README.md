# 松山市 行政区域境界データ

## 入手元
国土数値情報ダウンロードサービス: https://nlftp.mlit.go.jp/ksj/
「行政区域データ（N03）」の愛媛県（または全国）分をダウンロードする。

## ここに置くもの
ダウンロードした Shapefile または GeoJSON 一式をこのディレクトリに置く（県全体でよい。
スクリプト側で市区町村名属性 `N03_004`（または相当の列）が「松山市」の地物のみを
抽出してから、洪水・土砂・避難所データとの交差判定に使う）。

## 備考
このデータは他の洪水・土砂・避難所データを松山市域に絞り込むためだけに使用し、
それ自体はアプリの出力には含めない。
このディレクトリは `.gitignore` により Git 管理対象外（このREADMEのみ追跡）。
