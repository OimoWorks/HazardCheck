# 洪水浸水想定区域データ（想定最大規模 / L2）

## 入手元
国土数値情報ダウンロードサービス: https://nlftp.mlit.go.jp/ksj/

「洪水浸水想定区域データ」の愛媛県分をダウンロードし、「想定規模」は **想定最大規模** を選択する。

## ⚠️ 対象となる河川区分について
想定最大規模（L2）のデータは、河川区分にかかわらず作成されている
（`data/raw/flood-l1/README.md` 参照）。そのため、このディレクトリには

- **洪水予報河川・水位周知河川** 区分の想定最大規模データ
- **その他の河川** 区分の想定最大規模データ

の**両方**をダウンロードして置く（ファイルが区分ごとに分かれている場合は両方とも
このディレクトリ直下に置いてよい。スクリプトはディレクトリ内のファイルをまとめて読み込む）。

## ここに置くもの
`data/raw/flood-l1/` と同様に、ダウンロードした Shapefile または GeoJSON 一式を
このディレクトリ直下に置く（複数ファイルになる場合はすべて置く）。

## 属性の想定
浸水深ランクを表す属性は **`A31a_205`**（想定最大規模の浸水ランク）である。
`data/raw/flood-l1/README.md` の「属性の想定」を参照（`A31a_105` を `A31a_205` に
読み替える）。コード値の実際の出現状況は `npm run build:hazard-data` 実行時の
コンソール出力で確認できる。
