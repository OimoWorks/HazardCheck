# 洪水浸水想定区域データ（計画規模 / L1）

## 入手元
国土数値情報ダウンロードサービス: https://nlftp.mlit.go.jp/ksj/

サイト内の「洪水浸水想定区域データ」を検索し、**愛媛県**分をダウンロードする。
「想定規模」が選べる場合は **計画規模（従来規模）** を選択すること。
形式は Shapefile と GeoJSON のどちらかを選べる場合が多いが、**GeoJSON が選べるならGeoJSONを推奨**。

## ⚠️ 対象となる河川区分について
洪水浸水想定区域データは、河川の区分によって作成されているデータが異なる。

- **洪水予報河川・水位周知河川**: 計画規模（L1）・想定最大規模（L2）の**両方**のデータが存在する
- **その他の河川**: **想定最大規模（L2）のデータのみ**存在し、計画規模（L1）のデータは
  そもそも作成されていない

したがって、このディレクトリ（`flood-l1`）には **「洪水予報河川・水位周知河川」区分の
計画規模データのみ**を置く。「その他の河川」区分のデータをダウンロードしても計画規模の
ファイルは含まれていないはずなので、ここには置かない（`flood-l2/` 側にのみ置く）。

この区別があるため、アプリ側の診断ロジックでは、計画規模（L1）に該当ポリゴンがない地点を
単純に「区域外」とはせず、そもそも計画規模データを持つ河川の流域内かどうかで
「区域外」（流域内だが浸水想定なし）と「データなし」（その他の河川の流域＝L1データ自体が
存在しない）を出し分けている。この判定用に、`scripts/build-hazard-data.js` が
`flood-l1/` の全ポリゴンから流域の近似範囲（凸包＋バッファ）を自動計算し、
`data/processed/flood-l1.json` の `coverage` フィールドに保存する
（`src/lib/hazardLookup.js` 参照）。そのため、**このディレクトリにはL1データが存在する
河川分のポリゴンを漏れなく置くことが重要**（範囲計算の精度に直接影響する）。

## ここに置くもの
ダウンロードしたzipを解凍し、中身のファイル一式をこのディレクトリ直下にそのまま置く。

- GeoJSONの場合: `*.geojson` または `*.json`（1ファイルでも複数ファイルでも可。
  スクリプトはこのディレクトリ内の `.geojson`/`.json` を自動検出する）
- Shapefileの場合: `*.shp` `*.dbf` `*.shx` （`*.prj` があれば併せて置く）を同じベース名で置く

## 属性の想定
浸水深ランクを表す属性（列名は年度・提供形式により異なる。例: `A31a_101` のような連番コードや
`浸水ランク` 等の日本語列名の場合がある）が含まれる。
`scripts/build-hazard-data.js` 実行時にコンソールへ検出した属性名一覧が出力されるので、
実際の列名を確認して `scripts/build-hazard-data.js` 内の `FLOOD_RANK_FIELD_CANDIDATES` に
実データの列名を追記すること。
