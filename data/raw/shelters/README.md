# 避難所データ（国土地理院 指定緊急避難場所データポータル）

⚠️ 以前このREADMEでは国土数値情報「指定緊急避難場所データ（P20）」の利用を案内していたが、
P20は2012年度を最後に更新が止まっている古いデータのため使用しない。
代わりに、国土地理院が公開する **指定緊急避難場所データポータル**
（<https://hinanmap.gsi.go.jp/hinanjocheck/>）から、松山市分（市区町村コード「38201」）の
CSVを取得して使用する。

## 入手手順（手動ダウンロード）

このポータルはJavaScriptで動的にテーブルを表示する形式のため、開発者が実際にサイトを
ブラウザで開いてダウンロードする必要がある（自動取得は行わない）。

1. <https://hinanmap.gsi.go.jp/hinanjocheck/> を開く
2. 都道府県「愛媛県」→ 市区町村「松山市」（市区町村コード `38201`）を選択する
3. 表示された一覧から、以下の2種類のCSVをダウンロードする
   - **指定避難所データ**（ファイル名の例: `38201_1.csv`） — 災害発生後に一定期間滞在する
     ための施設（学校・公民館等）。列: `NO,共通ID,施設・場所名,住所,指定緊急避難場所との住所同一,
     その他市町村長が必要と認める事項,受入対象者,緯度,経度,備考`
   - **指定緊急避難場所データ**（ファイル名の例: `38201_2.csv`） — 災害の種類ごとに
     緊急避難先として指定されている場所。列: `NO,共通ID,施設・場所名,住所,洪水,崖崩れ、
     土石流及び地滑り,高潮,地震,津波,大規模な火事,内水氾濫,火山現象,指定避難所との住所同一,
     緯度,経度,備考`（各災害種別の列は該当時 `1`、非該当時は空）

## ここに置くもの

ダウンロードした2つのCSVファイルをこのディレクトリ直下にそのまま置く
（文字コードはUTF-8、BOM付きで配布される想定。`scripts/build-hazard-data.js` はBOMを
自動的に除去する）。

`scripts/build-hazard-data.js` はファイル名ではなく **ヘッダー列の内容**（`洪水` `地震` 列の
有無）で「指定緊急避難場所データ」か「指定避難所データ」かを判定するため、ダウンロード時に
ファイル名が変わっていても問題ない。

- 指定緊急避難場所データの行は、災害種別フラグから `disasterTypes`（該当する災害種別の配列）を
  付与して `data/processed/shelters.json` に出力する
- 指定避難所データの行は `disasterTypes: []`（全災害種別で共通の長期滞在避難所という位置づけ）
  として出力し、`受入対象者`（要配慮者向け等）があれば `acceptedGroups` に格納する
- どちらも `category` フィールド（`"指定緊急避難場所"` または `"指定避難所"`）で区別できる

## 松山市分の絞り込みについて

ポータル側で市区町村コード `38201`（松山市）を指定してダウンロード済みのため、
このCSVの内容はそのまま信頼して使用する（`data/raw/matsuyama-boundary/` の境界ポリゴンに
まだダミーデータしか置かれていない段階では、ダミー境界で再フィルタすると実データが
誤って除外されてしまうため、境界フィルタは適用しない）。`matsuyama-boundary` に実データを
配置した後は、整合性チェックとして境界ポリゴンとの `booleanPointInPolygon` 判定も
自動的に適用されるようになる。
