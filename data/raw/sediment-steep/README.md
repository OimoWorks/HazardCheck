# 土砂災害警戒区域データ（急傾斜地の崩壊）

## 入手元
国土数値情報ダウンロードサービス: https://nlftp.mlit.go.jp/ksj/

「土砂災害警戒区域データ」の愛媛県分をダウンロードする。区域種別が
「急傾斜地の崩壊」「土石流」「地すべり」でファイルが分かれている場合は、
**急傾斜地の崩壊** 分をこのディレクトリに置く。

もし3種類が1つのファイルにまとまっている場合は、その1ファイルだけをこのディレクトリに
置けばよい（`scripts/build-hazard-data.js` が地物ごとの区域種別属性を見て自動的に
「急傾斜地の崩壊」「土石流」「地すべり」に振り分ける）。その場合
`data/raw/sediment-debris/` `data/raw/sediment-landslide/` は空のままでよい（同じファイルを
重複して置くと集計が重複するので置かないこと）。

## ここに置くもの
Shapefile（`*.shp` `*.dbf` `*.shx` `*.prj`）または GeoJSON（`*.geojson`/`*.json`）一式。

## 属性の想定
警戒区域／特別警戒区域の別を表す属性列がある想定（例: `区域区分` 等）。
実際の列名は `scripts/build-hazard-data.js` 実行時のコンソール出力で確認し、
`SEDIMENT_ZONE_FIELD_CANDIDATES` に追記すること。
